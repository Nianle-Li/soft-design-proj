## 1. 需求分类与追踪规则

- `REQ-*` 表示可实现的功能需求，`INV-*` 表示任何命令都不能破坏的全局不变式，`AC-*` 表示验收场景，`AMB-*` 表示题目未明确之处。
- 只有题目明确规定的文本属于精确输出契约；其余输出按项目约定实现，并与题目要求区分。
- 验收场景覆盖正常、失败、关键边界及编辑命令的撤销重做；题目未规定的行为按项目决策实现，并与题目原生要求区分。
- 若题目补充明确规则，应更新对应契约、实现和测试。

## 3. 文档与历史状态

### 3.1 文档状态

- 启动时允许“无当前文档”状态。
- `init [w] [h]` 创建当前空文档；缺省尺寸为 `800×600`。
- `read <file.svg>` 用读入结果替换当前文档，并记住其读入路径以支持无参数 `save`。
- `save [file.svg]` 序列化当前文档；无参数时使用读入时的路径。
- `canvas` 是只读查询；`canvas <w> <h>` 修改当前画布尺寸。
- 未 `init`/`read` 时执行需要文档的命令，题目规定错误为 `error: no document. use 'init' or 'read' first`。哪些纯帮助命令例外见 `AMB-001`。

### 3.2 历史状态机

| 事件                                     | 文档效果                 | 历史效果                                                                    |
| ---------------------------------------- | ------------------------ | --------------------------------------------------------------------------- |
| 成功编辑命令                             | 应用一个原子变化         | 压入 undo；清空 redo；若此前处于 I/O 屏障，则重新允许 undo/redo             |
| 失败命令                                 | 无                       | undo、redo 和屏障状态全部不变                                               |
| `tree` / `show` / `help` / `canvas` 查询 | 无                       | 跳过历史，既不入栈也不改变屏障                                              |
| 成功 `undo`                              | 撤销最近一个编辑单元     | 该单元转入 redo                                                             |
| 成功 `redo`                              | 重做最近被撤销的编辑单元 | 该单元转回 undo                                                             |
| undo 后执行新的成功编辑                  | 应用新变化               | 清空 redo                                                                   |
| 成功 `init` / `read` / `save`            | 按命令语义处理           | 建立 I/O 屏障；随后 undo/redo 报 `error: undo not allowed after io command` |
| 成功 `canvas <w> <h>`                    | 修改尺寸                 | 与 I/O 命令相同，建立历史屏障                                               |

题目未规定空历史栈的输出或 I/O 屏障前旧记录的内部存储方式。项目采用清空历史栈的实现，外部行为按上表执行；见 `AMB-002`。

## 4. 命令级契约

### 4.1 文档命令

| ID      | 语法              | 成功与状态语义                                                    | 历史     | 主要失败/边界                                             |
| ------- | ----------------- | ----------------------------------------------------------------- | -------- | --------------------------------------------------------- |
| REQ-001 | `init [w] [h]`    | 新建空画布；默认 `800×600`；示例输出 `canvas 800x600 created`     | I/O 屏障 | 数值合法性见 `AMB-003`                                    |
| REQ-002 | `read <file.svg>` | 读入 SVG 为当前文档；为缺 id 元素按“标签名+序号”补 id，并逐个警告 | I/O 屏障 | `error: cannot read file: a.svg`                          |
| REQ-003 | `save [file.svg]` | 输出浏览器可直接预览的 SVG；无参数时保存至读入路径                | I/O 屏障 | `error: cannot write file: a.svg`；无既有路径见 `AMB-004` |
| REQ-004 | `canvas`          | 显示当前画布尺寸                                                  | 不入历史 | 无文档                                                    |
| REQ-005 | `canvas <w> <h>`  | 修改当前画布尺寸                                                  | I/O 屏障 | 数值合法性见 `AMB-003`                                    |

### 4.2 创建命令与参数规则

所有创建语法均可追加 `in <containerId>`；省略时挂到 SVG 根，指定时挂到已存在的 `g`。成功创建是一条可撤销编辑命令。

| ID      | 类型      | 参数                                             | 可选样式的省略语义 |
| ------- | --------- | ------------------------------------------------ | ------------------ |
| REQ-010 | `rect`    | `create rect <id> <x> <y> <w> <h> [fill]`        | 不写 `fill`        |
| REQ-011 | `circle`  | `create circle <id> <cx> <cy> <r> [fill]`        | 不写 `fill`        |
| REQ-012 | `ellipse` | `create ellipse <id> <cx> <cy> <rx> <ry> [fill]` | 不写 `fill`        |
| REQ-013 | `line`    | `create line <id> <x1> <y1> <x2> <y2> [stroke]`  | 不写 `stroke`      |
| REQ-014 | `text`    | `create text <id> <x> <y> "content"`             | 文本写为子文本     |
| REQ-015 | `g`       | `create g <id>`                                  | 创建空容器         |
| REQ-016 | `in` 子句 | 上述任意类型尾部追加 `in <containerId>`          | 创建时直接表达归属 |

创建前必须先完成全部校验。重复 id 使用 `error: id already exists: <id>`；未知类型按
`error: unknown shape type: <type> (is the plugin loaded?)`；不存在的目标容器使用
`error: no such container: <id>`；目标不是 `g` 使用 `error: not a container: <id>`。

Phase 1 内置类型严格限定为 `rect`、`circle`、`ellipse`、`line`、`text`、`g`。`box` 不属于本阶段，见第 9 节。

### 4.3 编辑命令

| ID      | 语法                            | 成功与状态语义                                                             | 必须保存的撤销事实（非架构决定）       |
| ------- | ------------------------------- | -------------------------------------------------------------------------- | -------------------------------------- |
| REQ-020 | `delete <id>`                   | 删除目标；目标为容器时删除整棵子树                                         | 原父节点、原索引和被删子树引用         |
| REQ-021 | `move <id> <dx> <dy>`           | 按增量平移；容器整体平移                                                   | 足以施加反向位移的信息                 |
| REQ-022 | `scale <id> <factor>`           | 正因子同乘全部几何属性（位置与尺寸）；容器递归处理所有子孙                 | 足以恢复原几何值的信息；不得保存全文档 |
| REQ-023 | `set <id> <attr> <value>`       | 只允许白名单属性；text 内容属性名为 `text`                                 | 目标、属性是否原先存在及原值           |
| REQ-024 | `group <newGid> <id1> <id2>...` | 新建 `g`，从原父节点摘出所有目标并收入，保持相对顺序；整个操作一个历史单元 | 每个目标的原父节点/索引和新容器位置    |
| REQ-025 | `ungroup <gid>`                 | 解散非根级普通 `g`；子节点在该组原位置提升到其父节点                       | 原组、父节点、索引和子节点顺序         |
| REQ-026 | `addto <gid> <id>`              | 将已有图形从原父节点移至目标组，成为最后一个子节点                         | 原父节点、原索引                       |
| REQ-027 | `front <id>`                    | 将图形调整到同级“最前”                                                     | 原同级索引                             |
| REQ-028 | `back <id>`                     | 将图形调整到同级“最后”                                                     | 原同级索引                             |

共同失败要求：目标 id 不存在时使用 `error: no such shape: <id>`；任何参数、层级或属性校验失败均满足 `INV-002`。

额外明确错误：

- `scale` 因子不为正：`error: scale factor must be positive`。
- 白名单外属性：`error: unknown attribute: <attr>`。
- group 参数同时包含某容器和其后代：`error: cannot group a container into its own descendant: <id>`。
- 解散 SVG 直接子节点的容器：`error: cannot ungroup top-level container: <id>`。

### 4.4 `set` 属性白名单

| 适用对象 | 属性                             |
| -------- | -------------------------------- |
| 公共     | `fill`、`stroke`、`stroke-width` |
| rect     | `x`、`y`、`width`、`height`      |
