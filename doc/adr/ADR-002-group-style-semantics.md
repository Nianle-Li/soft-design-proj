# ADR-002：普通容器的样式设置语义

- 状态：已接受（Phase 1 普通 `g` 的公共样式属性）
- 确认来源：用户在比较“组上保存并继承”与“递归改写后代”后明确选择方案 A。
- 依据：`../../phase_cli_1.md` §2.1、§3、§4.1；`../requirements.md` 的 `REQ-023`、`INV-005`、`INV-007`、`INV-008`、`AMB-005`。

## 问题与候选

`set <id> <attr> <value>` 必须支持三项公共样式属性，也必须让叶子与普通 `g` 遵守统一的适用操作语义。题目没有规定对普通 `g` 设置样式时是否改写后代。候选 A 把 `fill`、`stroke`、`stroke-width` 写在目标 `g` 自身，依 SVG 继承影响未显式覆盖的后代；候选 B 递归改写后代的显式属性。

候选 A 只改变一个元素的属性，既保留子节点显式覆盖，也让以后新增的子节点自然继承；序列化保留 SVG 原生结构。候选 B 会覆盖既有显式样式，撤销需要记录多处旧值，新增子节点还需额外传播机制。后续 `box` 插件示例定义的是该复合类型自己的传播行为，不能反推为普通 `g` 的规则。

## 决定与边界

采用候选 A。`set g1 fill red` 只设置 `g1` 的显式 `fill`；子孙的显式属性和值均不变。撤销恢复 `g1` 原有值；若原来缺失，则撤销后重新缺失，不补写默认值。普通 `g` 不接受叶子专有几何属性；未知属性按题目给定文本报错，失败不得修改文档或历史。

公共样式状态在 `model` 内封装并复用，几何白名单与数值规则由各具体图形负责。`editor` 的具体 Command 只保存本次属性更改的最小反向信息，Invoker 管理一条命令一个历史单元；`cli` 只解析命令并格式化摘要。既有 `cli → editor → model` 依赖方向不变，不增加新的业务模块或设计模式。`svg` 读写实现时应保留元素自身显式属性，而不把继承结果写回子元素。

数值合法性的精确范围仍属 `AMB-003`，不是本次用户确认内容。当前局部策略与既有创建规则保持一致：几何设置接受有限数字；`stroke-width` 暂接受有限非负数字，不扩展到完整 SVG 长度语法。空的 `fill`/`stroke` 暂拒绝。若教师给出更具体的数值或单位要求，应调整这些校验与测试，不改变本 ADR 的组继承语义。

## 验证与复议

- 对六种图形/容器逐项测试白名单；普通组与嵌套组的样式仅存于目标组，显式覆盖的子节点不变。
- 测试可选样式从缺失到存在、覆盖原值、undo 恢复缺失或原值、redo，以及未知属性和非法数值的失败原子性。
- SVG 读写切片加入组属性和子节点显式覆盖的 round-trip；后续 `box` 插件采用自己的传播语义，不修改普通组规则。
- 若教师对普通 `g` 明确给出不同语义，或 SVG 读写暴露兼容性冲突，再复议本 ADR；当前决定不覆盖 `transform`、CSS 完整语法及插件阶段。
