# ADR-011：box 读回降级与结构保护

- 状态：已接受并实现。
- 依据：Phase 2 §4、Phase 1 §4.4 与 §6.1；重复 id 必须拒绝整次读入。

## 结构所有权

比较两种保护方式：

| 方案                                                  | 收益                                                 | 代价与风险                                                                   |
| ----------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------- |
| 每次按 `<boxId>-rect`、`<boxId>-label` 查询文档并判断 | 不在对象中保存引用                                   | 插件需访问文档索引；改名或畸形树可能误保护；规则泄漏到删除、移动和解组调用方 |
| `BoxShape` 持有创建时验证过的必要子部件引用           | 不变量由容器自身封装；普通结构命令继续只调用容器权限 | 读回必须先验证结构再构造对象                                                 |

选择第二种。box 是可继续收纳子节点的容器，但框体 rect 与标题 text 是插件拥有的必要部件；直接删除、移走、分组这些部件均由 `assertCanDetach` 拒绝。删除或移动整个 box 仍按普通子树处理。`assertCanUngroup` 精确报 `cannot ungroup composite shape: <id>`。创建提供者只经 `ShapeCreationContext` 请求 rect/text，文档既有整树预检统一拒绝根或派生 id 冲突，失败前不接入任何成员。

## 读回与降级

安装 box 插件时，`<g data-kind="box">` 必须恰有前两个必要直接子节点：`rect#<id>-rect` 与 `text#<id>-label`，类型、id、顺序或数量不符均拒绝为 `invalid box structure: <id>`；额外直接子节点允许作为 box 收纳的内容。严格拒绝比静默降级更能暴露已声明 box 的损坏，且避免后续属性传播指向错误对象。

未安装插件时，同一元素由普通 `g` 提供者读回，忽略 `data-kind="box"` 并保留全部子树、顺序和普通容器操作；再次保存可丢失该语义标记，这是明确的语义降级，不丢失可见图形内容。任何模式下，显式或派生重复 id 均由文档级预检拒绝整份读入，不以降级绕过。

创建、整体操作、必要部件保护、语义标记分派、严格读回、属性传播和 `(box)` 标签均通过同一公开扩展契约接入。专用反馈不在宿主按 box 类型分支：创建回执通用携带复合子树标签，属性计划声明传播目标或文本语义，CLI 只格式化结构化结果。box 的领域标签为 `box#id`，独立树投影为 `g#id (box)`，因此 §6.1 的创建、移动、fill、label 和 undo 文案均可满足而不泄漏插件类型。
