# ADR-006：ShapeProvider 与模型拆分契约

- 状态：**C+ 方向已由用户确认；接口签名和实现门禁待测试，不作为已实现能力**。
- 决策日期：2026-11-23。
- 依据：Phase 2 §1、§4、§6 要求所有旧图形也经注册、`box` 接入时内核差异为零、插件只依赖公开抽象；Phase 1 §4.1、§4.4、§6.1 约束旧语法与 `box` 语义。边界方向沿用 [ADR-005](ADR-005-phase2-plugin-boundaries.md)。

## 当前阻碍和不变量

`src/model/` 的 14 个文件混有领域规则、六种具体图形与 `ShapeFactory`。后者同时解析 CLI 参数、SVG 属性并按六种 `kind` 构造对象；`ShapeSpec` 是封闭联合。`SvgDocument` 持有工厂、直接 `new GroupShape`，并用 `instanceof GroupShape` 判断收纳、解组与父子关系；`Shape.visitSubtree` 的父类型也写死为 `GroupShape`。直接搬目录不会得到 B+ 的边界。

必须同时保留：旧命令、错误、树、SVG 字节及 `final` 会话；没有可选插件时六种旧图形仍可用；一次创建是一笔 undo；提供者或子树校验失败不改变文档和历史；`read` 失败不替换会话。`box` 可嵌套、整体操作，派生子部件 id，禁用插件时降级读成普通 `g`；重复 id 必须拒绝整次读入。此处决定通用容器保护机制，不决定异常 box 结构是拒绝还是警告降级、哪些子部件受保护及属性处理器事务；这些留给对应 ADR。

## 可行路线

| 路线                          | 做法                                                               | 长处                                         | 关键代价或缺陷                                                                      |
| ----------------------------- | ------------------------------------------------------------------ | -------------------------------------------- | ----------------------------------------------------------------------------------- |
| A：注册解析器、保留中央构造   | 提供者只返回扩大的 `ShapeSpec`，`ShapeFactory` 仍按 `kind` 构造    | 与旧代码接近，短期改动少                     | 每加图形须扩联合与核心构造分支；`box` 子树仍需核心特判，不能满足 OCP 和接入提交判据 |
| B：受控事务式构造             | 提供者获得临时文档写入端口；框架记录操作并在成功时提交、失败时回滚 | 可渐进构造复杂图形，原子性也可由框架统一保证 | 须公开插入、移除、父子与回滚协议；提供者在构造时感知文档状态，undo 契约更宽         |
| C：提供者返回分离的完整图形树 | 提供者构造候选树；文档验证、接入并保存局部逆操作                   | 创建原子性和图形知识边界清楚                 | 只覆盖创建，未处理后来删除或移走必要子部件、多目标编辑中途失败                      |
| **C+：分离树与窄容器约束**    | 保留 C 的单次接入，并让容器在结构编辑前检查移出与解组规则          | 同时约束创建和后续编辑；不公开文档写入事务   | 文档须在多目标操作开始前检查全部目标，容器检查必须无副作用                          |

**选择 C+**。A 无法通过新增类型的接入判据；B 可实现要求，却需较宽的事务写端口；原 C 未覆盖创建后的结构编辑。C+ 把插件的创建工作限制在分离对象树，把文档状态变更集中在统一接入点，同时用窄容器约束处理后续编辑。该选择不以初次改动量为优劣标准。

## 建议的最小公开面

1. `src/core/model/` 定义 `ShapeProvider`、`Shape`、`ContainerShape`、`SvgDocument` 和只读视图。提供者声明唯一类型名、SVG 标签及可选语义标记；创建方法接收 id 与该类型的参数，读回方法接收不含 DOM 类型的只读元素输入及已经递归读好的子图形。提供者返回**尚未接入文档**的 `Shape` 或完整 `ContainerShape` 子树，不接收文档可变索引或历史。图形的 SVG 标签与语义类型分别表达；`box` 的 SVG 标签是 `g`，树标签和插件分派不得解析 `g#id` 文本猜语义。
2. 创建上下文只提供按已注册类型请求子图形的能力。`box` 用它请求默认 `rect`、`text` 提供者，不能导入具体类；测试可换入替身。SVG 适配器负责 XML、命名空间、根画布、缺失 id 的赋值与文本节点；类型专有属性和子结构由提供者检查。核心按语义标记优先选提供者，未注册的 `g` 标记回退普通 `g`；普通 SVG 的其他未知属性仍按旧规则报错。
3. `ContainerShape` 表示可收纳子节点，与“允许解组”分开。普通 `g` 是内置具体类；`box` 是可收纳但不可解组的插件类。容器提供无副作用的移出子节点与解组预检；插件可拒绝移走必要子部件并给出领域错误，不暴露文档索引。`SvgDocument` 只依赖容器抽象，`group` 从已注册的 `g` 提供者取得新容器，不构造或辨认具体 `GroupShape`。解组时先执行容器约束，再应用根级容器限制，保证 `box` 的规定错误优先。
4. 文档在任何接入前以对象身份和 id 检查整棵候选树：无环、无重复节点/重复 id、id 合法、与现有索引无冲突、容器关系有效；成功后整体索引并接入。创建收据只保留本次树根、父容器、位置与必要的局部逆信息；撤销/重做对整棵初始子树操作，不复制整份文档。提供者抛错或返回违规结构时不改变文档与历史，并给出可辨识的错误。对 `group` 等会移动多个现有节点的操作，文档先检查全部来源容器及目标条件，再开始修改，不能移走一部分后才遇到受保护子部件。
5. `src/builtin/shapes/` 放六种具体图形及其提供者，只通过 `src/core/plugin-api.ts` 取公开基类、契约与受控创建上下文。`src/host/assembly/` 默认注册这些内置提供者，禁用所有可选插件仍恢复 Phase 1 行为。旧 `ShapeFactory` 的解析逻辑分配给各自提供者后移除；封闭 `ShapeSpec` 不作为新类型的扩展协议。

接口形状以上述职责为准，精确 TypeScript 签名在首个契约测试中固定；不得为了通过目录检查引入仅转发调用的空层。公开的参数输入不应迫使核心解析 CLI token 或 XML DOM。

## 行为路径与验证门禁

- `create`：宿主得到类型名与参数 → 核心按名称选择提供者 → 提供者构造分离树（可通过上下文组合其他提供者）→ 文档整树预检并接入 → 编辑命令保存收据。失败时索引、树和 undo/redo 深度不变；撤销和重做针对同一棵树。
- `group`、`addto`、`delete`：文档先向来源容器询问是否允许移出；`group` 必须检查全部被收编目标后才修改任一节点。容器拒绝时结构与历史不变。撤销整棵 `box` 不逐个移走其必要子部件；解组先调用容器的许可检查。
- `read`：SVG 适配器产生中性输入并分配缺失 id → 注册机制递归选提供者并构造候选树 → 文档整树预检 → 全文成功后会话替换。没有 `box` 提供者时带其标记的 `g` 读成普通分组；重复 id 先于降级拒绝。
- 首个实现切片先以**假提供者**测试注册/选择/禁用、未知类型、返回重复 id/非法 id/共享节点/循环引用、失败不入历史以及整树 undo/redo；再实现最小核心契约。容器切片须用假受保护子部件测试 `delete`、`addto`、`group` 的拒绝和 `group` 后遇到拒绝时的整体原子性。后续分别迁移普通 `g` 与五种叶子提供者、SVG 读回和旧 `ShapeFactory`；每步都跑 `final` 字节基线。`box` 插件只在通用契约已通过后接入，并用源码差异证明核心与旧插件不变。
- 替换 XML 解析器只改 `src/adapters/svg/` 与装配；新增图形只新增实现及装配/配置，`src/core/`、`src/host/cli/` 和旧插件均不改。检查器逐步删除旧 `src/model/` 例外，最终拒绝核心导入 `src/builtin/`。

## 已确认与后续决策

- 用户确认 **C+：分离树 + 文档统一校验/接入 + 窄容器约束**，并将“可收纳”与“可解组”分离。实现仍须以反例测试证明上述职责，不能把目录搬迁当成架构完成。
- 具体错误文本、`ShapeProvider` 参数类型、读回中性输入的最小字段，待首个契约测试定稿；不得预先固定未见插件需要的宽接口。
- 异常 `box` 读回与必要子部件保护在 box ADR；属性处理器回滚、dirty 与装配清单时机各在其 ADR 决定。本提案不替代这些决策。
