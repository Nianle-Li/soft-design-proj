# sw-design-lab

软件设计课程项目：Phase 1 SVG 命令行编辑器。

当前处于开发准备阶段：已建立可复现的 TypeScript/Vitest 基线、协作规则和课程文档模板；具体架构将在设计讨论后确定。

## 开始使用

```powershell
npm install
npm run typecheck
npm run lint
npm run format:check
npm test
npm run cli
```

详细的开发规则见 [AGENTS.md](AGENTS.md)，课程交付文档与需求追踪见 [doc/README.md](doc/README.md)。
